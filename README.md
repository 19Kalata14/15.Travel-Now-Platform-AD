# Фирма №15 — TravelNow Platform AD

Курсов проект по **Мрежова и информационна сигурност (МИС)**, ТУЕС.

## За фирмата

TravelNow Platform AD е онлайн туристическа агенция с технически офис в София,
контактен център в Монтана и партньорски офис в Кюстендил. Платформата обработва
резервации и плащания. Платежният шлюз (PCI-DSS зона) е строго изолиран.

- **Тип субект по ЗКС:** важен субект (important entity)
- **Сектор:** цифров доставчик / онлайн пазар (Приложение 2 на ЗКС)

## Архитектура на лабораторията

| Сегмент | Мрежа | Роля |
|---|---|---|
| WAN  | NAT | Изход към интернет |
| LAN1 (Tech) | 10.140.0.0/24 | Booking API, Payment GW (PCI) |
| LAN2 (Office) | 10.141.0.0/24 | Контактен център (Монтана) |

**Виртуални машини:** `gw` (шлюз/защитна стена, nftables, NAT) и `srv` (услуги).

## Структура на проекта

| Папка | Сесия | Съдържание |
|---|---|---|
| `artefakti/s01-laboratoria/` | 1 | Базова лаборатория — топология, мрежа, IP forwarding, NAT |
| `artefakti/s02-razuznavane/` | 2 | Разузнаване — nmap, изброяване на уеб пътища, анализ на риска, MITRE ATT&CK Navigator |
| `artefakti/s03-kontroli/` | 3 | Регулаторни изисквания — матрица на проследимост (NIS2 / ЗКС) |
| `artefakti/s04-risk/` | 4 | Оценка на риска (ISO 27005) — регистър на активите, регистър на риска, план за третиране |
| `artefakti/s05-politika/` | 5 | Политика за сигурност — платежна среда (PCI), адресира риск R-01 |

## Използвани рамки и стандарти

- **MITRE ATT&CK** — заплахи и техники в регистъра на риска
- **ISO/IEC 27001 / 27005** — система за управление и оценка на риска
- **NIS2 / ЗКС / НМИМИС** — регулаторни изисквания
- **PCI-DSS** — защита на платежната среда
